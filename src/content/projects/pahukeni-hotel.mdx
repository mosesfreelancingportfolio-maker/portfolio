## Overview

Pahukeni Pension Hotel Management System is a web application built to help Pahukeni Pension Hotel in Namibia manage its daily hotel operations. It centralizes bookings, customer information, and operational data into one efficient system.

## The problem

Running a hospitality business on manual processes is error-prone. Bookings were tracked by hand, customer data was repeated across spreadsheets, and staff had no single, up-to-date view of what was happening across the hotel.

## My solution

- **Web dashboard** for staff to manage bookings and operations
- **Centralized customer and reservation records**
- **Clear workflows** for check-in, check-out, and availability
- **Backend and database** to keep everything consistent and queryable

## Architecture

- **Frontend**: React-based web dashboard
- **Backend**: API handling bookings and customer data
- **Database**: PostgreSQL for reliable relational data

## Technologies

- Next.js
- React
- TypeScript
- REST API
- PostgreSQL

## Implementation

Built around the daily operations of the hotel: staff manage bookings and customer records through the dashboard, and the backend keeps all data consistent and reliable so there is always a single source of truth for hotel operations.

## Impact

Removed the manual spreadsheets and gave the hotel a practical tool for running bookings and customer data more efficiently.
